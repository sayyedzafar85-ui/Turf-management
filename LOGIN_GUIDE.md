# 🏏 Turf Management System - Login Guide

## 📍 Separate Login Portals

This system has **TWO SEPARATE** login portals for different user types:

---

## 🔴 Super Admin Portal

**Access URL:** `https://sportslots-4.preview.emergentagent.com/super-admin-login`

**Who uses this:**
- Platform administrators
- System owners who manage multiple turfs

**What you can do:**
- ✅ View all turfs across the platform
- ✅ Create new turf admins
- ✅ View platform-wide analytics
- ✅ Monitor total bookings & revenue
- ✅ Manage all turf owners

**Default Credentials:**
```
Username: superadmin
Password: Admin@123
```

**⚠️ Important:** This is a restricted access area. Only super administrators should use this portal.

## 🔐 Security Features

1. **Separate Authentication:** Super admins and turf admins use different login portals
2. **Role-Based Access:** Each role has specific permissions
3. **JWT Tokens:** Secure session management
4. **Access Control:** Super admins cannot accidentally login to turf portal and vice versa
